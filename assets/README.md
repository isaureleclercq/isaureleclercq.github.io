# Portfolio assets

Put exported project images here. Use short, lowercase filenames, for example `identity-study-cover.jpg`.

For the cleanest project cards, export a landscape image around 1400 × 1000 px. JPG or WebP works well for photos and composites; PNG works well for graphics with transparency. Keep source files in Adobe apps or Google Drive and add only the web-ready export here.

## House renovation model

`house-renovation.jpg` is a cropped browser capture of the actual Autodesk Fusion model supplied for this portfolio, not a generated architectural rendering. Source model: [Design Renovation Model](https://mystu70109.autodesk360.com/g/shares/SH90d2dQT28d5b602811bbc0bcde42f199b0).

The image is a static snapshot. Recapture it when the design changes; the interactive Autodesk viewer follows the shared model.
